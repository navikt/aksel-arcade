# Allow Agentation source reuse with attribution

Aksel Arcade may directly copy and adapt Agentation source into Arcade-owned modules for the annotation feature where that is the fastest and clearest way to preserve Agentation behavior, schema, and agent workflow semantics. Arcade should not add Agentation as a runtime dependency because the UI visuals/CSS must be translated to Aksel, the preview interaction must fit Arcade's iframe boundary, and project/share/MCP behavior must stay Arcade-native. The v0.3.0 PRD should not re-grill Agentation-default behavior; details not explicitly changed by Arcade decisions can be handled during implementation by copying or adapting Agentation behavior and source. Visual/CSS translation is the intended design-system override, while Agentation's interaction timing, easing, and default functional behavior should be preserved unless an Arcade-specific decision says otherwise. The maintainer has determined that Aksel Arcade is not a competing product with Agentation because Arcade is an editor tied to use of the Aksel design system, so PolyForm Shield's non-compete condition does not block this use. Project attribution for Agentation should be added to the README acknowledgments alongside other technology acknowledgements; copied or adapted source does not require a bespoke file-level notice unless implementation discovers a mandatory notice requirement in the reused source.

Agentation references: use the pinned Agentation repository state at [`benjitaylor/agentation@8158a97c`](https://github.com/benjitaylor/agentation/tree/8158a97c10c37e577b0a6e2d3175d143918216cd), the [root README](https://github.com/benjitaylor/agentation/blob/8158a97c10c37e577b0a6e2d3175d143918216cd/README.md), the [package README](https://github.com/benjitaylor/agentation/blob/8158a97c10c37e577b0a6e2d3175d143918216cd/package/README.md), and the [PolyForm Shield license file](https://github.com/benjitaylor/agentation/blob/8158a97c10c37e577b0a6e2d3175d143918216cd/LICENSE) when creating implementation tasks or copying/adapting source.
