# Shared Aksel insertion catalog for authoring aids

Aksel Arcade will use one curated **Aksel insertion catalog** as the source of truth for `+Add` and code autocomplete insertions, while generated Aksel documentation data remains the source for prop and prop-value suggestions. The catalog is curated because behavior-complete Arcade examples sometimes need simplified docs examples, replacement-policy filtering, runtime verification against the pinned Aksel package version, and multi-part insertion into JSX plus Hooks; using raw docs entries directly would recreate invalid top-level subcomponent suggestions and one-string snippets that render or behave incorrectly. A manual docs-audit script should fetch fresh Aksel docs and report catalog drift during upgrades without making ordinary tests depend on the network.
