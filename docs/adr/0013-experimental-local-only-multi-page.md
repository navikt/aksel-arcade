# Experimental, local-only multi-page

While multi-page authoring is behind the experimental **Workspace preference**, the portable artifacts — **Web share URL**, `.akselarcade` **Arcade project package**, and the share snapshot — remain single-page and carry only the **start page**, with an explicit warning to the user that other pages are not included. We are not yet versioning these formats to carry the Global config and full page set. Portable-format versions are hard to reverse once recipients exist in the wild, share URLs already have a payload-size guard that many pages would strain, and the multi-page design is still proving out behind a flag. The trade-off is that sharing or exporting a multi-page prototype is lossy today; we prefer warned, backward-compatible degradation now over prematurely committing to a multi-page wire format. When the feature graduates from the flag, extending the portable formats (lossless, version-bumped, backward-compatible on read) is the planned follow-up and should get its own ADR.
