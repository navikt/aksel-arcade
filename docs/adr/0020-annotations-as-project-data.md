# Annotations are Arcade project data

Annotations are durable review information attached to one Arcade page in an Arcade project, not local workspace state, Preview evidence, or a Desktop-only agent session. They travel with the same shell-neutral project data as source and preview preferences in `.akselarcade` packages and in Web share URLs when the full annotation data fits within the URL payload boundary, so humans and External agents see the same annotations in Web Arcade and Desktop Arcade. Adding annotations requires a project/package/share payload version bump, with backward migration from missing `annotations` to an empty annotation set. We prioritize complete, agent-useful annotation data over URL portability: Web share creation must not silently drop or truncate important annotation metadata, and if the full annotated project is too large for a Web share URL it should warn/fail and direct the user to `.akselarcade` export instead. Arcade must not offer or automatically create a reduced Web share URL without annotations as the fallback, because that would separate review context from the prototype artifact. Explicit context replacement actions such as Reset editor, built-in template/demo loads, applying a Web share URL, importing a package, or future replace-project flows reset the entire annotation set rather than preserving old review information across a new prototype context. We accept the larger share/package boundary because page-scoped annotations are part of the prototype review artifact; keeping them session-only would make handoff and Desktop MCP behavior diverge from the project a user is sharing.

Agentation references: Agentation describes copy/structured-output sharing in its [root README](https://github.com/benjitaylor/agentation/blob/8158a97c10c37e577b0a6e2d3175d143918216cd/README.md) and implements markdown output in [`package/src/utils/generate-output.ts`](https://github.com/benjitaylor/agentation/blob/8158a97c10c37e577b0a6e2d3175d143918216cd/package/src/utils/generate-output.ts); Arcade intentionally replaces that sharing model with Arcade project package and Web share URL persistence.
