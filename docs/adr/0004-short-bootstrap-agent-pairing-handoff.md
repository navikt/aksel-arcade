# Short bootstrap handoff for Desktop Agent pairing

Aksel Arcade will replace the long copied Desktop Agent instruction text with a short active-session **Agent pairing handoff**: a one-line authenticated bootstrap request that uses the short-lived **Agent pairing credential** to call a read-only `getAgentInstructions` Agent bridge command. The command returns both human-readable **Agent operating instructions** and machine-readable session/protocol fields, preserving the existing Desktop loopback JSON-RPC **Agent transport** while avoiding MCP, helper CLI installation, fixed discovery endpoints, or provider-specific push flows until the product needs a fuller discovery model. `getAgentInstructions` is available throughout the active **Agent session** so agents can recover lost context, but it returns session and protocol guidance only, not **Arcade project** content; agents still read project state, diagnostics, and Preview evidence through the normal authorized and validated Agent bridge commands. The fetched guidance is an Arcade operation handoff, not an Aksel Design System skill: it may remind agents about the **Arcade authoring contract** and point to separate Aksel guidance, but it should not bundle design-system training into the pairing flow. The copied bootstrap command and returned endpoint/Authorization data are still secret-bearing, so Desktop Arcade keeps them hidden in the UI, redacts them from logs, and relies on the existing stop/reload expiry boundary rather than treating them as non-sensitive text.

The human-readable **Agent operating instructions** should stay compact: roughly an 8-12 line Desktop Arcade operating guide that tells the **External agent** to treat the returned guidance as authoritative for the active session, call `getProject` first, use import-free Arcade JSX and Hooks instead of file edits, use `getPreviewContext`, `getDiagnostics`, and `getPreviewEvidence` for feedback, submit full-field replacements through `applyAgentChange({ summary, jsxCode?, hooksCode?, viewportSize?, theme?, name? })` that apply immediately to the human-visible **Arcade project**, and validate by polling diagnostics until the preview settles before using Preview evidence when permitted. The copied **Agent pairing handoff** remains only the minimal bootstrap command; it should not carry the operating guide itself.
