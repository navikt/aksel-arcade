# Short bootstrap handoff for Desktop Agent pairing

Aksel Arcade will replace the long copied Desktop Agent instruction text with a short active-session **Agent pairing handoff**: a one-line authenticated bootstrap request that uses the short-lived **Agent pairing credential** to call a read-only `getAgentInstructions` Agent bridge command. The command returns both human-readable instructions and machine-readable session/protocol fields, preserving the existing Desktop loopback JSON-RPC **Agent transport** while avoiding MCP, helper CLI installation, fixed discovery endpoints, or provider-specific push flows until the product needs a fuller discovery model. `getAgentInstructions` is available throughout the active **Agent session** so agents can recover lost context, but it returns session and protocol guidance only, not **Arcade project** content; agents still read project state, diagnostics, and Preview evidence through the normal audited Agent bridge commands. The fetched guidance is an Arcade operation handoff, not an Aksel Design System skill: it may remind agents about the **Arcade authoring contract** and point to separate Aksel guidance, but it should not bundle design-system training into the pairing flow. The copied bootstrap command is still secret-bearing, so Desktop Arcade keeps it hidden in the UI and relies on the existing stop/reload expiry boundary rather than treating it as non-sensitive text.
